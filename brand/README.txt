TAP AM — BRAND KIT (v1.0, October 2026)

Start with Tap-Am-Brand-Guidelines.pdf: it explains how to use everything here.

01-logo        Wordmark. SVG masters (use these first) + PNG at 600 / 1200 / 2400 px wide.
               primary = for light backgrounds · reverse = for dark backgrounds · mono = one colour
02-mark        The finger mark (SVG + PNG).
03-app-icon    App icon, favicons, PWA icons, Apple touch icon, notification badge.
04-social      Link-share image (1200x630), landing posters and background video loops.
05-colours     colours.css (CSS variables), colours.json, colours.txt (HEX / RGB / CMYK).
06-fonts       Barlow + Barlow Condensed (TTF). Free under the SIL Open Font License (OFL.txt).
               Install: double-click each .ttf (Windows/Mac) or add to Canva/Figma as uploaded fonts.
07-characters  20 rank characters, 8 badges, 5 stickers (SVG + PNG).
08-patterns    10 seamless patterns: overlay/ (transparent, place on any colour) and on-colour/ examples.
